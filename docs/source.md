# 乡村配送来源约定

目录和详情分别位于 /catalog 与 /detail，对应浏览器页面以 .html 结尾。详情使用目录中的稳定标识，不用显示名称做业务键。edition 为 1 或 2，表示两个发布期；交接站、游标和签收回执是本地演练资料中的业务语义。来源只监听环回地址，没有真实人员、订单或账号。

## 业务语义与采集映射

- 运单业务键是目录稳定标识 `id`；`group` 是交接站；发布期 `edition` 即游标 `revision`，在采集目录时写入每个条目的 revision。
- 同一运单的每个游标代表一次实际交接，自然键 `id#r<revision>`。最新游标代表运单当前路线；改派（新发布期、可能换交接站）只新增交接，历史交接不可改写。
- 详情 `detail` 是签收回执内容；edition 2 的 `changed_detail` 用于演练凭证内容更换。凭证以内容 SHA-256 指纹区分版本：同指纹为重复上传，不同指纹为待核新版本。
- 凭证缺席的交接统一呈现“待核”，禁止推断为未签收；凭证可先于或晚于到站表到达，两种顺序最终关联结果一致。
- 每次读取的原始响应作为不可变收据只追加保存；采集游标记录在 progress 中，重启后按未关联原件补齐，保证原件与交接记录之间不留落差。
